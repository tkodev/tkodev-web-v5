# Process

Working loop — front-loaded on distillation and direction before any build:

> Gather inspiration → distill the essence → set direction → design → thin slice → feedback → iterate → harden → polish.

Docs 01–03 (this doc, the brief, the observations) are the **path toward the design** — the gathering, distillation, and direction-setting. The **Figma file is the designed solution** that path produces, and ultimately the source of truth, transcribed into [06-design.md](06-design.md). Once direction settles: **plan → thin slice → harden → make it shine**. The thin slice is one page built end-to-end through the riskiest layer (the cinematic system over real data); hardening extends the system across pages; polish is the signature pass.

## Priority frame

1. **The Problem** — one or two sentences.
2. **The Hardest Failure Mode** — what breaks worst; design around it first.
3. **Key Design Decisions** — the load-bearing choices everything else hangs off.
4. **What to Prototype First** — the riskiest slice to validate early.
